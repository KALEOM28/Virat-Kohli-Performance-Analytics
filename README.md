# 🏏 Virat Kohli Career Performance Analytics (Power BI)

## 📌 Project Overview
This project delivers a comprehensive, data-driven analysis of one of cricket's greatest batsmen, **Virat Kohli**. Using a detailed dataset of his international matches, I built an interactive **Power BI Dashboard** to break down his batting trends, run milestones, performance against rival countries, and ground-wise success.

## 🛠️ Tech Stack & Skills Used
- **Data Visualization:** Power BI (Desktop)
- **Data Transformation:** Power Query (Cleaning date formats, sorting matches, and aggregating historical runs)
- **Data Source:** `Source.csv` (Contains match-by-match metrics: runs, opponent, ground, date, match type, and cumulative totals)

## 🔍 Key Insights Explored from the Dataset
- **Format & Match Analysis:** Visualizes how Kohli accumulates runs across different formats (ODI, Test, T20) relative to the number of innings played.
- **Opponent Insights:** Tracks total runs and centuries scored against major cricketing nations (like Australia, Sri Lanka, England, etc.) to show his favorite opponents.
- **Ground & Venue Dominance:** Highlights specific stadiums and grounds (both home and away) where he has the highest batting average or total runs.
- **Milestone Timeline:** Plots a cumulative line chart (`total` runs over time) showing his career growth and how fast he crossed milestones.

## 🚀 Purpose of this Project
This project demonstrates the ability to take complex sports statistics, clean them using Power Query, and build an engaging story that any sports enthusiast or stakeholder can easily understand at a glance.
